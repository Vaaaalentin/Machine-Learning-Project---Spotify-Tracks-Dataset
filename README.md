Project Organization
The objective of this project is to apply the Machine Learning concepts and methods covered
in class to a real-world problem related to your engineering specialization.
• Team formation: Students must work in groups of 2 to 4 students. Working in pairs
is encouraged.
• Project topic: Each group must select a topic related to its major or engineering
specialization.
• Project approach: The project must address a clearly identified problem using a
relevant Machine Learning approach.
• Language: All project deliverables and presentations must be written and presented
in English.
Each group is responsible for defining its project scope, identifying appropriate data, and
proposing an initial experimental strategy.
Step 1 – Choose a Project Topic
Select a topic connected to your major and identify a problem that could be addressed using
Machine Learning.
Your topic should:
• Be relevant to your engineering field or specialization.
• Address a concrete problem or a clearly defined research question.
• Have a potential Machine Learning application.
• Be sufficiently focused to be completed within the available project timeframe.

Step 2 – Identify and Collect the Dataset
Find one or more datasets that will allow you to investigate your selected problem. You can
see these project examples.
You may use:
• Public datasets (Kaggle, UCI Machine Learning Repository, Hugging Face Datasets,
OpenML, etc.).
• Open data portals.
• Scientific datasets published with research papers.
• Data collected or generated by your group, provided that the collection process is clearly
described and feasible.
When selecting a dataset, consider:
• Its relevance to the problem.
• The number of observations and available features.
• The type of data (numerical, categorical, textual, images, time series, etc.).
• Data quality and the presence of missing values.
• The availability of target labels, if required.
• Any restrictions concerning access, usage, or licensing.
You must provide the source of the dataset and explain why it is suitable for your project.
Expected outcome: A dataset description, its source, and a justification of its suitability.

1 Step 4 – Define Your Baseline
Before exploring more advanced approaches, establish a baseline that will serve as a reference
for evaluating your future models.
A baseline is a simple and reproducible method against which more sophisticated approaches can be compared.
Depending on your problem, possible baselines include:
• A majority-class or random classifier.
• A simple statistical prediction model.
• Linear or logistic regression.
• A decision tree.
• A basic k-nearest neighbors model.
You must specify:
• The baseline algorithm you intend to use.
• Why this baseline is appropriate.
• The evaluation metrics you will use.
• How you will split your data into training, validation, and test sets.
Your baseline should be implemented early in the project. It will help you determine
whether more advanced models actually provide an improvement.
Expected outcome: A clearly identified baseline model and an initial evaluation strategy.

2 Step 5 – Write the Project Specification
Each group must prepare a short synthesis of its project specifications (requirements document).
The document must include the following sections:
1. Project Title: A concise and informative title.
2. Team Members: Names of all group members.
3. Context and Motivation: Description of the application domain and the motivation
behind the project.
4. Problem Statement: The problem you aim to solve and the main research question.
5. Project Objectives: The expected outcomes and measurable objectives.
6. Dataset Description: Data source, size, features, target variable (if applicable), and
potential limitations.
7. Machine Learning Task: Classification, regression, clustering, or another relevant
task.
8. Baseline Strategy: Selected baseline algorithm and justification.
9. Evaluation Strategy: Data splitting methodology, evaluation metrics, and validation
approach.
10. Initial Work Plan: Main tasks and their distribution among team members.
The document must be concise, clear, and technically justified. It should demonstrate
that your group has identified a feasible Machine Learning problem and has a realistic plan
to address it.

• An initial work plan.
Important: The project topic, dataset, and baseline must be sufficiently defined before

Project Timeline: 4 Weeks
The project will be conducted over four weeks. Each week corresponds to a specific milestone,
with clearly identified objectives and deliverables.
1. Week 1 – Project Definition and Data Collection
Objectives:
• Form teams of 2–4 students.
• Select a topic related to your major.
• Define the problem and research question.
• Identify and collect a suitable dataset.
• Perform an initial exploratory data analysis.
Deliverable: Project specification document (2–3 pages), including the problem statement, dataset description, objectives and initial work plan.
2. Week 2 – Data Preparation and Baseline
Objectives:
• Clean and preprocess the dataset.
• Analyze features, missing values and target distribution.
• Define training, validation and test sets.
• Select and implement a baseline model.
• Evaluate initial performance using appropriate metrics.
Deliverable: Clean dataset, baseline implementation and initial experimental results.
3. Week 3 – Model Development and Experimentation
Objectives:
• Select and implement one or more Machine Learning models.
• Train and evaluate the models.
• Experiment with feature selection and hyperparameter tuning.
• Compare results against the baseline.
• Analyze errors and identify potential limitations.
Deliverable: Experimental results and comparison with the baseline.
4. Week 4 – Evaluation and Final Presentation
