## 📋 Project Organization

The objective of this project is to apply the Machine Learning concepts and methods covered in class to a real-world problem related to your engineering specialization.

* **Team formation:** Groups of **2 to 4 students** (working in pairs is encouraged).
* **Project topic:** Must be related to your major or engineering specialization.
* **Project approach:** Must address a clearly identified problem using a relevant Machine Learning approach.
* **Language:** All project deliverables and presentations must be written and presented in **English**.

Each group is responsible for defining its project scope, identifying appropriate data, and proposing an initial experimental strategy.

---

## 🚀 Kick-off Steps

### Step 1 – Choose a Project Topic
Select a topic connected to your major and identify a problem that could be addressed using Machine Learning.

**Criteria:**
* Relevant to your engineering field or specialization.
* Addresses a concrete problem or a clearly defined research question.
* Has a potential Machine Learning application *(prediction, classification, regression, clustering, anomaly detection, recommendation systems, computer vision, NLP, time-series analysis)*.
* Sufficiently focused to be completed within the available project timeframe.

> **Expected outcome:** A short description of the topic, the problem to be addressed, and its relevance to your major.

---

### Step 2 – Identify and Collect the Dataset
Find one or more datasets that will allow you to investigate your selected problem using:
* Public datasets *(Kaggle, UCI Machine Learning Repository, Hugging Face Datasets, OpenML, etc.)*
* Open data portals
* Scientific datasets published with research papers
* Data collected or generated by your group *(provided the collection process is clearly described and feasible)*

**Selection Checklist:**
* [ ] Relevance to the problem
* [ ] Number of observations and available features
* [ ] Type of data *(numerical, categorical, textual, images, time series, etc.)*
* [ ] Data quality and presence of missing values
* [ ] Availability of target labels *(if required)*
* [ ] Restrictions concerning access, usage, or licensing

> **Expected outcome:** A dataset description, its source, and a justification of its suitability.

---

### Step 3 – Define the Machine Learning Problem
Translate your initial topic into a well-defined Machine Learning problem by specifying:
* **Task:** Classification, regression, clustering, etc.
* **Input variables:** Features.
* **Target variable:** When applicable.
* **Expected output:** Format and nature of the predictions.
* **Evaluation criteria:** Performance metrics.

Clearly formulate the main objective of your project as a **question** or a **measurable goal**.

> **Expected outcome:** A precise formulation of the Machine Learning problem and its objectives.

---

### Step 4 – Define Your Baseline
Before exploring advanced approaches, establish a simple and reproducible baseline to serve as a reference for evaluating future models *(e.g., majority-class/random classifier, simple statistical model, linear/logistic regression, decision tree, basic k-NN)*.

**You must specify:**
* The baseline algorithm you intend to use and **why** it is appropriate.
* The evaluation metrics you will use.
* How you will split your data into **training, validation, and test sets**.

> **Expected outcome:** A clearly identified baseline model and an initial evaluation strategy.

---

### Step 5 – Write the Project Specification
Prepare a concise, technically justified requirements document (**~2–3 pages**) containing the following sections:

1. **Project Title:** A concise and informative title.
2. **Team Members:** Names of all group members.
3. **Context and Motivation:** Description of the application domain and motivation.
4. **Problem Statement:** The problem to solve and the main research question.
5. **Project Objectives:** Expected outcomes and measurable objectives.
6. **Dataset Description:** Data source, size, features, target variable, and potential limitations.
7. **Machine Learning Task:** Classification, regression, clustering, or other.
8. **Baseline Strategy:** Selected baseline algorithm and justification.
9. **Evaluation Strategy:** Data splitting methodology, evaluation metrics, and validation approach.
10. **Initial Work Plan:** Main tasks and their distribution among team members.

---

## 📦 Initial Deliverables (End of Kick-off)

* [ ] Short project specification document *(~2–3 pages)*
* [ ] Link to the selected dataset and its source
* [ ] Clearly formulated Machine Learning problem
* [ ] Description of the proposed baseline
* [ ] Initial work plan

> ⚠️ **Important:** The project topic, dataset, and baseline must be sufficiently defined before moving on to the implementation phase.

---

## 📅 Project Timeline (4 Weeks)

### Week 1 – Project Definition and Data Collection
* **Objectives:** Form teams (2–4 students), select a topic, define the problem/research question, collect a suitable dataset, and perform initial Exploratory Data Analysis (EDA).
* **Deliverable:** Project specification document (2–3 pages).

### Week 2 – Data Preparation and Baseline
* **Objectives:** Clean and preprocess the dataset, analyze features/missing values/target distribution, define train/val/test splits, implement the baseline model, and evaluate initial performance.
* **Deliverable:** Clean dataset, baseline implementation, and initial experimental results.

### Week 3 – Model Development and Experimentation
* **Objectives:** Implement advanced ML models, train/evaluate, experiment with feature selection and hyperparameter tuning, compare against the baseline, and perform error analysis.
* **Deliverable:** Experimental results and comparison with the baseline.

### Week 4 – Evaluation and Final Presentation
* **Objectives:** Finalize experiments and evaluation, compare models and interpret results, discuss limitations and improvements, and prepare the final report and presentation.
* **Deliverables:** Final report, source code/notebook, and oral presentation.
